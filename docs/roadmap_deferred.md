# Ограничения версии 1.1 и планы

- **Игроки и боты** не двигаются модулем (их ведёт собственный код движения). Для ботов
  есть `goldnav_find_path`.
- **Лестницы (func_ladder), прыжки через провалы, плавание** — не поддерживаются: entity ходит,
  поднимается на ступеньки, запрыгивает на уступы (если задана высота прыжка) и спрыгивает вниз.
- **Двери** entity сама не открывает: закрытая дверь для неё стена, открылась — сетка обновится.
  Постоянно движущиеся объекты (поезд на ходу, вращающийся вентилятор) в сетку не попадают,
  пока не остановятся.
- **Отрисовка пути** в плагине-курице (`goldnav_find_path`) не знает о высоте прыжка: луч
  показывает путь пешком, а прыгающая курица может пойти короче.
- **Триггеры** (trigger_hurt, телепорты и т.п.) на ведомую entity не срабатывают: движок
  не трогает триггеры при перестановке origin. Touch с твёрдыми entity эмулируется.
- **Анимация** — забота плагина. Для своих entity используйте `MOVETYPE_PUSHSTEP`
  (плавная интерполяция на клиенте); с `MOVETYPE_STEP` нужно самим обновлять `animtime`.
- **Обход подвижных препятствий** — локальный (шаг вбок), без взаимного уклонения толпы.
- **Частичный путь**: если цель недостижима, entity подходит как можно ближе и результат
  всё равно `ARRIVED` (флаг `GOLDNAV_MOVE_EXACT` превращает это в `FAILED`).
- Навмеш не кэшируется на диск — строится заново на каждой карте (обычно < 2 с).
- Сборка под MSVC не проверялась (проверены llvm-mingw и gcc).
