# Серверные команды и квары GoldNav

Команды — только серверная консоль / rcon.

## Команды

- `goldnav_status` — состояние слоёв навмеша (узлы, очередь генерации), сколько entity ведётся,
  сколько динамических объектов отслеживается и сколько стоящих коробок учтено в сетке.
- `goldnav_rebuild` — перестроить навмеш заново (например, после смены `goldnav_cell_size`).
- `goldnav_findpath x1 y1 z1 x2 y2 z2 [hull=2]` — найти путь и напечатать точки.
  `hull`: 0 point, 1 ducking, 2 standing, 3 large.
- `goldnav_dump <файл> [layer=1]` — выгрузить узлы слоя в бинарный файл в папке игры
  (формат описан в `src/metamod/admin_commands.cpp`).

## Квары

- `goldnav_cell_size` (16) — шаг сетки, 8..32. Меньше — точнее в узких местах, но больше
  узлов. Применяется при `goldnav_rebuild` / смене карты.
- `goldnav_gen_budget_ms` (8) — сколько миллисекунд кадра можно тратить на генерацию.
- `goldnav_max_drop` (150) — с какой высоты entity ещё может спрыгнуть с уступа.
- `goldnav_max_jump` (64) — до какой высоты строить рёбра-прыжки (0 — не строить). Сама entity
  прыгает не выше, чем ей задано через `goldnav_set_jump_height`. Применяется при
  `goldnav_rebuild` / смене карты.
- `goldnav_dynamic` (1) — следить за дверями и поставленными на карту entity и перестраивать
  сетку вокруг них. 0 — навмеш статичный, как в 1.0.
- `goldnav_debug` (0) — 1: рисовать лучами сетку вокруг первого игрока (зелёный — шаг,
  красный — спрыгивание, синий — прыжок) и пути идущих entity (жёлтый); писать в консоль причины
  перестроения путей. Для отладки, не для боевого сервера.

Высота ступеньки и гравитация берутся из движковых `sv_stepsize` и `sv_gravity`.
